┌─ PROBLEMAS COMUNS ──────────────────────────────────────────────────────────┐
│                                                                               │
│  ❌ "Porta 3001 já está em uso"                                              │
│     → Feche outro programa usando essa porta                                 │
│     → Ou: PORT=3002 npm run server                                           │
│                                                                               │
│  ❌ "Cannot find module"                                                     │
│     → Execute: npm install                                                   │
│                                                                               │
│  ❌ Página em branco                                                          │
│     → Pressione: Ctrl + Shift + R (limpar cache)                             │
│                                                                               │
│  ❌ "Liturgia não disponível"                                                │
│     → Verifique se servidor está rodando: http://localhost:3001/api/health  │
│     → Verifique conexão de internet                                          │
│     → Verifique se site da CNBB está online                                  │

│  ❌ Erro no console (F12)                                                    │
